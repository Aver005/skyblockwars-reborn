# 04 — SkyBlockWars Reborn (игра)

Правила конкретной игры и её настройка. Каркас (арены, лобби, отсчёты, откат мира,
снапшоты, статистика) — в [01-architecture.md](01-architecture.md); здесь — только
то, что добавляет игра. Вся игровая специфика живёт в пакете
`ru.kiviuly.skyblockwars.sbw` (наследник `Minigame`), ядро игро-независимо.

## Как играется матч

1. **Спавн = блок возрождения.** Каждого телепортирует на свою точку по кольцу;
   под ногами — один блок, он же якорь возрождения. Пока его не сломал чужой игрок,
   при гибели игрок возрождается на нём (3 сек неуязвимости).
2. **Добыча своего блока.** Ломая свой блок, игрок получает его содержимое (обычный
   блок — сам блок; контейнер — вложенный лут), блок восстанавливается СЛУЧАЙНЫМ
   блоком текущей эпохи (по весам), и это `+1` к рубежу эпохи.
3. **Эпохи.** Набор блоков с весами + рубеж (сколько своих блоков сломать до смены).
   Достиг рубежа — следующая эпоха. Последняя эпоха или рубеж `-1` — остаётся до конца.
   Прогресс — в боссбаре. Режим: `personal` (у каждого своя цепочка) или `shared`
   (общая на арену) — переключается per-arena.
4. **Слом чужого якоря.** Сломал блок возрождения врага — тот теряет респавн и
   выбывает при СЛЕДУЮЩЕЙ смерти (не мгновенно).
5. **Таймлайн.** 30 мин обычной игры → ломаются ВСЕ блоки возрождения + 5 мин схватки
   (респавнов нет) → разрушение арены: поставленные игроками блоки хаотично исчезают.
   Победитель — последний выживший (есть предохранитель от «вечной» ничьей).
6. **Лобби-дуэль.** В лобби включён PvP без смертей (авто-хил); считается нанесённый
   урон, на старте матча объявляется лидер разминки. На матч не влияет (отключается
   `skyblockwars.lobby-duel: false`).

## Настройка арены (без правки YAML руками)

Спавны НЕ ставят вручную — они генерируются кольцом от центра:

```
/sbw create <ID>              создать арену (мир = твой текущий; встань в пустом мире)
/sbw setcenter <ID>           центр = твоя позиция; спавны встают по кольцу
/sbw setmaxplayers <ID> <n>   число игроков (и точек по кольцу)
/sbw setradius <ID> <n|default>   радиус кольца
/sbw setmode <ID> personal|shared режим продвижения эпох
/sbw settime <ID> match|fight <n|default>  длительность фазы (обычная/схватка)
/sbw epochs <ID>              GUI-редактор эпох
/sbw setlobby <ID>            лобби (место лобби-дуэли) = твоя позиция
/sbw check <ID>               валидатор  →  /sbw enable <ID>
```

Изменение центра/радиуса/макс-игроков пересобирает кольцо спавнов. Настройка
недоступна, пока на арене идёт матч.

## Редактор эпох (`/sbw epochs <ID>`)

Продвинутое GUI, всё сохраняется сразу в `game/<ID>.yml`:

- **Список эпох** — порядок = последовательность. ЛКМ — редактировать, ПКМ — удалить,
  Shift+ЛКМ/ПКМ — двигать вверх/вниз. Кнопки: «+ Добавить эпоху», «Режим эпох»,
  «Время фаз» (правка `match`/`fight` ± кликами). На незанятой арене список засевается
  набором по умолчанию как шаблон.
- **Эпоха** — имя (наковальня), рубеж (± кликами, `-1` = финальная), сетка блоков и
  пять способов наполнить её блоками:
  - «+ Добавить блок» — палитра всех ставящихся блоков (вес 1);
  - «Добавить из инвентаря» — блоки из твоего инвентаря (кол-во каждого = вес);
  - «Добавить из сундука» — блоки из контейнера, на который смотришь (кол-во = вес);
  - «Скопировать из эпохи» — глубокая копия блоков другой эпохи (веса + лут) сюда;
  - «Наследуемые эпохи» — выбрать эпохи, чьи блоки ПОДМЕШИВАЮТСЯ при спавне, НЕ
    копируясь (динамически, транзитивно, с защитой от циклов).
- **Блок** — вес появления (± кликами), «Лут контейнера» (для сундуков/бочек/шалкеров),
  удаление.
- **Лут контейнера** — открывается реальный инвентарь по размеру контейнера: что
  положишь — то и появится внутри блока при спавне. Сохраняется по закрытию.

Наследование против копирования: копия — одноразовый снимок (правишь независимо);
наследование — живая ссылка (меняешь родителя — меняется и наследник). Одинаковые
материалы при импорте из инвентаря/сундука сливаются в один блок, веса складываются.

## config.yml — секция `skyblockwars`

| Ключ | Смысл |
|---|---|
| `radius-default` | радиус кольца по умолчанию (`/sbw setradius <ID> default`) |
| `epoch-mode-default` | режим эпох для новых арен (`personal`/`shared`) |
| `match-seconds` | ДЕФОЛТ обычной фазы (1800 = 30 мин); копируется в конфиг арены при создании, правится `/sbw settime` / GUI |
| `fight-seconds` | ДЕФОЛТ схватки (300 = 5 мин); аналогично копируется и правится per-arena |
| `destruction-rate` | доля оставшихся поставленных блоков, исчезающих в секунду |
| `destruction-max-seconds` | предохранитель: добить оставшихся, если разрушение затянулось |
| `lobby-duel` | включить лобби-разминку (PvP без смертей + учёт урона) |

Ядровой `arena-defaults.match-duration-seconds` = 0 (таймингом матча управляет сама
игра), `hud.bossbar` = false (игра рисует свой боссбар прогресса эпох).

## Данные

- Ядро: `arenas/<id>.yml` — мир, лобби, спавны (кольцо), лимиты, тайминги.
- Игра: `game/<ID>.yml` — центр, радиус, режим эпох, длительности фаз, эпохи
  (`id` + `name` + `threshold` + `inherits` [id наследуемых эпох] + блоки с весами и
  вложенным лутом; `ItemStack`/`Location` сериализуются нативно). Файл материализуется
  сразу при `/sbw create` (с дефолтами таймингов/эпох), а не лениво.

## Где что в коде

`sbw/SkyBlockWarsGame` (хуки+команды), `sbw/SbwState` (состояние матча),
`sbw/SbwListener` (блоки/лобби-урон), `sbw/EpochBossBar`, `sbw/ArenaGameConfig`,
`sbw/RingSpawns`, `sbw/epoch/*` (модель эпох), `sbw/menu/*` (GUI). Обобщённые точки
расширения в ядре — хуки `Minigame` (см. [02-making-a-game.md](02-making-a-game.md)).
