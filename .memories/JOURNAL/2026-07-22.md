# 2026-07-22 — эпохи: импорт блоков, наследование, тайминги per-arena

Три фичи по редактированию эпох (запрос владельца).

## 1. Три новых способа наполнить эпоху блоками (GUI `/sbw epochs`)

В `EpochMenu` добавлены 4 кнопки (было тесно — заняли свободные слоты 46/48/50/52
нижнего ряда рядом с «+ Добавить блок»):
- **Из инвентаря** — блоки из инвентаря админа; кол-во каждого материала = вес.
- **Из сундука** — контейнер, на который смотрит игрок (`getTargetBlockExact(6)`);
  кол-во = вес.
- **Скопировать из эпохи** — `EpochPickMenu` в режиме COPY: глубокая копия блоков
  (веса + лут контейнера, `EpochBlock.copy()`) другой эпохи сюда.
Импорт из инвентаря/сундука сливает одинаковые материалы в один блок, веса
складываются (`EpochMenu.importItems`). Импорт НЕ забирает предметы у админа.

## 2. Наследование эпох (блоки без хранения)

- `Epoch` получил стабильный `id` (UUID) и список `inherits` (id других эпох).
- `Epoch.effectiveBlocks(all)` / `pickRandom(all)` — объединение своих блоков и блоков
  наследуемых эпох, транзитивно, с защитой от циклов (visited по id).
- Резолв на споне: `SbwState.pick(epoch)` (знает список эпох матча) — заменил прямые
  `epoch.pickRandom()` в `SkyBlockWarsGame.giveLoadout`/`mineOwnBlock`.
- GUI: кнопка «Наследуемые эпохи» → `EpochPickMenu` в режиме INHERIT (тумблер вкл/выкл
  каждой эпохи).
- Ссылки по `id`, а не индексу/имени — переживают переименование/переупорядочивание.
  Наследование ≠ копия: копия — снимок, наследование — живая ссылка.

## 3. Тайминги фаз per-arena + дефолт из глобального конфига

- Глобальные `skyblockwars.match-seconds`/`fight-seconds` — теперь ДЕФОЛТ, который
  копируется в `game/<ID>.yml` при СОЗДАНИИ арены (не лениво).
- Новый ядровой хук `Minigame.onArenaCreated(Arena)` — зовёт `ArenaManager.create`;
  `SkyBlockWarsGame` материализует игро-конфиг (`config(id)`).
- Правка per-arena двумя путями (по выбору владельца — «и то, и другое»):
  - команда `/sbw settime <ID> match|fight <n|default>` (+ таб-комплит);
  - кнопка «Время фаз» в `EpochListMenu` → `PhaseTimeMenu` (± кликами, шаг 10/60с).
