# STATE — текущее состояние

Last updated: 2026-07-22 (эпохи: 3 способа импорта + наследование; тайминги per-arena)

## Кратко

**SkyBlockWars Reborn** — мини-игра на базе шаблона MCMGP. Реализована игра целиком
(package `ru.kiviuly.skyblockwars`, плагин `SkyBlockWars`, команда `/sbw`, ветка
`develop`). Сборка зелёная (`build/libs/SkyBlockWars-1.0.0.jar`). Ядро осталось
обобщённым — вся игровая специфика в подпакете `sbw/` (наследник `Minigame`).

Суть игры: каждого телепортирует на свой спавн; блок под ним — блок возрождения.
Пока чужой не сломал — при гибели игрок возрождается. Ломая свой блок, игрок добывает
его содержимое, блок восстанавливается случайным из текущей эпохи (по весам), прогресс
идёт к рубежу эпохи (боссбар). 30 мин игры → слом всех блоков → 5 мин схватки →
разрушение арены (поставленные блоки исчезают). Победитель — последний выживший.

## Что реализовано — игра (`sbw/`)

- **`SkyBlockWarsGame`** (наследник `Minigame`) — оркестратор: команды, хуки матча,
  ломание блоков, эпохи, фазы, лобби-дуэль. Зарегистрирован в `SkyBlockWarsPlugin.onEnable`.
- **`ArenaGameConfig`** — per-arena игро-конфиг в ОТДЕЛЬНОМ файле `game/<ID>.yml`
  (центр, радиус, режим эпох, длительности фаз, эпохи, стартовый набор `kit`). Ядровой
  `Arena` не тронут; кольцо спавнов пишется в ядровой `arena.getSpawns()`. Дефолтные
  эпохи МАТЕРИАЛИЗУЮТСЯ в файл при первом обращении к конфигу (`config()`), иначе они
  жили «в памяти» (`defaultEpochs()`) и в файле не появлялись — частая путаница.
- **`RingSpawns`** — расстановка спавнов по окружности вокруг центра (равноудалённо,
  лицом к центру), блочные координаты (ядро добавляет +0.5).
- **`SbwState`** (в `GameSession.data()`) — состояние матча: режим/эпохи, per-player
  прогресс и блок возрождения, общий прогресс (SHARED), карта «блок→владелец»,
  фаза матча (NORMAL/FIGHT/DESTRUCTION), множество поставленных игроками блоков.
- **`EpochBossBar`** — per-player боссбар: прогресс эпохи → отсчёт схватки → разрушение.
- **`SbwListener`** — BlockBreak (свой блок = добыча+прогресс+рефилл; чужой = слом якоря),
  BlockPlace (учёт для разрушения), EntityDamage в лобби (дуэль без смертей).
- **`epoch/`** — `Epoch` (стабильный `id`, блоки+рубеж, список `inherits`,
  взвешенный `pickRandom()` по своим и `pickRandom(all)`/`effectiveBlocks(all)` по
  своим+наследуемым транзитивно с защитой от циклов), `EpochBlock` (материал+вес+лут
  контейнера, `copy()` — глубокая копия), `Containers` (какие блоки — контейнеры).
- **Наследование эпох** — `Epoch.inherits` держит `id` других эпох арены; их блоки
  ПОДМЕШИВАЮТСЯ при спавне (не копируются). Резолв на споне через `SbwState.pick(epoch)`
  (знает список эпох матча). Ссылки по `id` переживают переименование/переупорядочивание.
- **`menu/`** — продвинутый GUI редактора эпох: `EpochListMenu` (список/порядок/режим/
  «Время фаз»), `EpochMenu` (имя/рубеж/блоки + 5 способов наполнить: палитра, из
  инвентаря, из сундука, копия из эпохи, наследуемые эпохи), `BlockEditMenu` (вес/лут/
  удаление), `BlockPaletteMenu` (палитра всех блоков), `LootEditorMenu` (полный редактор
  лута контейнера), `EpochPickMenu` (выбор эпохи — режим COPY/INHERIT), `PhaseTimeMenu`
  (тайминги фаз ± кликами). Вход: `/sbw epochs <ID>`. Плюс `KitEditorMenu` — редактор
  стартового набора (`/sbw kit <ID>`, 36 слотов, броня авто-надевается; пусто = дефолт).
- **Добыча/смерть** — добыча своего блока идёт в ИНВЕНТАРЬ (+ эффект слома частицами +
  списание прочности инструмента, т.к. ванильное ломание отменяется); вещи при СМЕРТИ
  ВЫПАДАЮТ дропом (`trackEntity` для отката). Возрождение выдаёт свежий стартовый набор.

## Обобщённые хуки, добавленные в ЯДРО (годятся любой игре)

`Minigame`: `onLethalDamage` (респавн/выбывание), `allowLobbyPvp`, `onCommand`/
`tabComplete`/`helpLines` (делегирование подкоманд игре), `onReload`, `onArenaCreated`
(материализация игро-конфига с дефолтами при создании арены — зовёт `ArenaManager.create`),
`onArenaRemoved`, `onPlayerRemoved`. Их зовут `GameListener` (летальный урон/лобби-PvP),
`MinigameCommand` (делегирование), `GameSession.removePlayer`, `ArenaManager.create/delete`,
`SkyBlockWarsPlugin.reloadEverything`. Игровой специфики в ядре нет.

## Команды игры (сверх ядровых `/sbw`)

- `/sbw setcenter <ID>` — центр арены = твоя позиция, спавны встают по кольцу.
- `/sbw setradius <ID> <n|default>` — радиус кольца.
- `/sbw setmaxplayers <ID> <n>` — число игроков (и точек по кольцу).
- `/sbw setmode <ID> personal|shared` — режим эпох.
- `/sbw settime <ID> match|fight <n|default>` — длительность фазы (обычная/схватка) per-arena.
- `/sbw epochs <ID>` — GUI-редактор эпох (блоки, веса, лут, рубежи, режим, время фаз,
  импорт из инвентаря/сундука/эпохи, наследуемые эпохи).
